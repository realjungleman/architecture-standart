| F2    | Клиент может видеть список доступных депозитов с актуальными ставками                              |              |
| F3    | Клиент может подать заявку на депозит, оставив номер телефона и ФИО                              |              |
| F4    | Клиент может пройти идентификацию в отделении банка                              |              |

| F10    | Менеджер в бэк-офисе может обработать заявку на открытие депозита                               |              |
| F11    | Менеджер в бэк-офисе может подтвердить условия депозита в АБС банка                               |              |
| F12   | Клиент должен получить СМС-уведомления после подтверждения размера ставки и открытия депозита                                |              |
| **U**   | **Удобство использования (Usability)** |              |
| U1    | Соответствие для системы дизайну, принятой в компании                                |              |
| U2    | Наличие привычных цветов и брендированных элементов                                |              |
| **R**   | **Надёжность (Reliability)**           |              |
| R1    | Все сервисы должны работать 24/7                               |              |
| R2    | Доступность 99.9%                                |              |
| R3    | Наличие резервного ЦОДа, работающего вхолостую                                | Сервисы развернуты только на одном ЦОД             |
| R4    | При сбое ЦОД интернет-банк должен быть доступен и выдерживать нагрузку                                | Сервисы развернуты только на одном ЦОД             |
| **P**   | **Производительность (Performance)**   |              |
| P1    | Отклик по всем операциям должен занимать не более 1 секунды                                |              |
| P2    | Требуется предусмотреть горизонтальное масштабирование                                | Между серверами, приложениями и ЦОД             |
| **S**   | **Поддерживаемость (Supportability)**  |              |
| S1    | Необходимо разработать документацию                                |              |
| **+R**  | **+ Ограничения (Restrictions)**       |              |
| +R1    | АБС может масштабироваться только вертикально                                 |              |
| +R2    | Некоторые справочные данные загружаются больше секунды                                |              |
| +R3    | СУБД АБС перегружена, нельзя использовать ее для MVP                                |                                                    |
| +R4   | Избегать работы интернет-банка с API АБС напрямую                                |                                                     |
| +R5   | Использовать для бд MS SQL/Oracle либо совместимые с ними                           |                                                     |
| +R6   | Для очередей использовать Kafka                                | Текущая версия интернет-банка не поддерживает Kafka, потребуется перевод на микросервисы в части открытия депозитов                                                    |
| +R7   | Ставки по депозитам ведутся лишь в XLS-файлах                                |                                                     |
| +R8   | Обязательно наличие шифрование каналов передачи данных                                |                                                     |
| +R9   | Реализовать работы с СМС силами банка минуя подрядчика                                | Сейчас СМС реализован в ядре системы                                                    |
| +R10   | Небольшое количество клиентов на данный момент, с возможностью роста                                |                                                     |
| +R11   | АБС реализован на Delphi и Oracle, полностью внутри банка                               |                                                     |
| +R12   | Система колл-центра на Java Spring Boot, React.js, PostgreSQL                                |                                                     |
| +R13   | Интернет-банк реализован подрядчиком на ASP.NET и MS SQL, монолит                                |                                                     |
